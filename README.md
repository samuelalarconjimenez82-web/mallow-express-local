# Mallow Express

This project is a landing page and MVP for a local delivery business in Mallow, Ireland.

## Features
- Local food delivery landing page
- Restaurant category section
- Mallow-focused design and branding
- Driver and partner CTA sections
- Responsive layout

## Stack
- Next.js
- React
- TypeScript

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Notes
This project is a business concept built for Mallow Express and is inspired by modern local delivery platforms, without copying any brand.
